## 📑 Document & File Search

[← Back to Index](../README.md)

### Document & Slide Search
- [SlideShare](https://www.slideshare.net/) — Slides and presentations search  
- [Scribd](https://www.scribd.com/) — Books, documents, and academic resources  
- [DocumentCloud](https://www.documentcloud.org/) — Upload, organize, and search primary-source documents; widely used by journalists  
- [Issuu](https://issuu.com/) — Digital publishing platform for shared documents, magazines, and reports  
- [Yumpu](https://www.yumpu.com/) — Online publication platform and search for documents and magazines  

### File & Open Directory Search
- [Eyedex](http://eyedex.org/) — Open directory file search  
- [FilePursuit](https://filepursuit.com/) — File and open directory search engine  
- [Filesec.io](https://filesec.io/) — File and directory search focused on infosec content
- [Meawfy](https://meawfy.com/) - Mega.nz file search
- [Open Directory Search Tool](https://opendirsearch.abifog.com/) — Google-powered search focused on finding open directories, filterable by content type

### Paste & Text Storage
- [Pastebin](https://pastebin.com/) — Public paste/text-sharing service, frequently referenced in leak investigations  
- [PSBDMP](https://psbdmp.ws/) — Search engine indexing Pastebin dumps, including leaked credentials  
- [Defuse](https://defuse.ca/pastebin.htm) — Pastebin with encryption options
- [Rentry.co](https://rentry.co/) — Markdown paste service with custom URLs and edit history
