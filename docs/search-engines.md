## 🔍 Search Engines

[← Back to Index](../README.md)

### General Search Engines
- [Google](https://www.google.com) — The most widely used web search engine  
- [Bing](https://www.bing.com) — Microsoft’s search engine  
- [DuckDuckGo](https://duckduckgo.com) — Privacy-focused search engine  
- [Startpage](https://www.startpage.com) — Google results with enhanced privacy  
- [Yahoo Search](https://search.yahoo.com) — Web search with integrated news and content  
- [Yandex](https://yandex.com) — Russian search engine with strong image search  
- [Baidu](https://www.baidu.com/) — Leading Chinese search engine  
- [Swisscows](https://swisscows.com/en) — Family-friendly, privacy-based search  
- [Qwant](https://www.qwant.com) — European privacy-focused engine  
- [Brave Search](https://search.brave.com) — Independent index, privacy-first  
- [Mojeek](https://www.mojeek.com) — Independent UK crawler-based search  
- [MetaGer](https://metager.org/) — German metasearch engine with anonymization  
- [Ecosia](https://www.ecosia.org) — Eco-friendly search engine that funds tree planting  
- [Kagi](https://kagi.com/) — Subscription-funded, ad-free search engine with result personalization (150 free searches, then paid)  
- [SearXNG Instances](https://searx.space/) — Directory of public SearXNG instances, an open-source metasearch engine that anonymizes queries  

### Metasearch and Search Portals
- [100SearchEngines](https://www.100searchengines.com/) — Metasearch and portal hub (formerly AllTheInternet.com, which now redirects here)  
- [All-in-One Search](https://all-io.net/) — Browser new-tab page that runs searches across many engines, with the option to add your own  
- [Etools](https://www.etools.ch/) — Swiss metasearch engine that queries 17 search engines at once  
- [FaganFinder](https://www.faganfinder.com/) — Directory of search engines, encyclopedias, academic databases, archives, and newspaper collections  
- [MyAllSearch](https://www.myallsearch.com/) — Search engine that avoids tracking your queries  
- [WebCleaner](https://www.webcleaner.com/) — Search top internet search engines from one page  

### Academic and Research Search
- [Google Scholar](https://scholar.google.com/) — Search scholarly literature and academic papers  
- [Litmaps](https://app.litmaps.com/) — Visual literature discovery and citation network  
- [Semantic Scholar](https://www.semanticscholar.org/) — AI-powered academic search across 238+ million publications  
- [BASE](https://www.base-search.net/) — Bielefeld Academic Search Engine for scholarly resources (uses bot protection that can block automated access)  
- [CORE](https://core.ac.uk/) — Access millions of open access research papers  
- [WorldCat](https://search.worldcat.org/) — Global library catalog  
- [Internet Archive Scholar](https://scholar.archive.org/) — Full-text search of scholarly works preserved by the Internet Archive  
- [Google Dataset Search](https://datasetsearch.research.google.com/) — Search engine for datasets hosted across the web

### Specialized Search Engines
- [Social Searcher](https://www.social-searcher.com/) — Free social media search across profiles, posts, mentions, and hashtags, no login required  
- [Carrot2](https://search.carrot2.org/) — Clustered search results visualization (needs JavaScript)  
- [I Search From](https://isearchfrom.com) — Google search simulator for location, language, and device  
- [Marginalia](https://marginalia-search.com/) — Alternative search engine focusing on smaller, non-commercial sites  
- [Wiby](https://wiby.me/) — Search engine for the classic, lightweight web  
- [Million Short](https://millionshort.com/) — Search engine that omits top sites for discovery  
- [Common Crawl Index](https://index.commoncrawl.org/) — Query the URL index of Common Crawl's open web archives to find historical pages for a domain  
- [Media Search Tool](https://www.no-nonsense-intel.com/adverse-media-search-tool) — Adverse media OSINT search tool  
- [IsLegitSite](https://www.islegitsite.com/) — Check if a website is legit or scam  

### Internet-Wide Scanners
- [Shodan](https://www.shodan.io) — Search for internet-connected devices  
- [Censys](https://censys.com) — Search infrastructure and SSL certificates  
- [FOFA](https://fofa.so) — Internet-wide search engine  
- [ZoomEye](https://www.zoomeye.ai) — IoT and cyberspace search    
- [LeakIX](https://leakix.net) — Search exposed services and databases  
- [Netlas.io](https://netlas.io/) — Internet-wide search and analytics  

### Source Code & Cloud Bucket Search
- [PublicWWW](https://publicwww.com) — Search source code and analytics IDs of web pages  
- [Grep.app](https://grep.app/) — Search GitHub indexed source code (Grep by Vercel)  
- [searchcode](https://searchcode.com/) — Search, analysis, and file retrieval for public Git repositories  
- [osint.sh Public Buckets](https://osint.sh/buckets/) — Search publicly accessible cloud storage buckets on AWS S3 and Azure Blob  
- [GrayHatWarfare](https://buckets.grayhatwarfare.com) — Public S3 bucket search
