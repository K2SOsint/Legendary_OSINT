## 📝 Reporting & Visualization

[← Back to Index](../README.md)

### Investigation Case Management
- [Aleph (OCCRP)](https://aleph.occrp.org/) — Investigative data and case management platform; the relaunched Aleph Pro keeps public data and nonprofit-journalist access free, with commercial licensing added (freemium)  
- [Maltego Basic](https://www.maltego.com/pricing/) — Free spiritual successor of CaseFile, link analysis and case organization tool (freemium)  
- [Obsidian](https://obsidian.md/) — Note-taking app that stores notes privately on your device, usable offline (freemium)  
- [Joplin](https://joplinapp.org/) — Open-source note-taking app with end-to-end encrypted sync (free)  
- [Zotero](https://www.zotero.org/) — Collect, organize, cite, and share research sources (free)  

### Capturing tools & Web Scraping
- [Data Miner](https://dataminer.io/) — Browser extension that scrapes data from web pages into CSV or Excel (freemium)  
- [Forensic OSINT](https://www.forensicosint.com/) — OSINT web capture software (commercial)  
- [Hunchly](https://hunch.ly/) — Web capture and investigation case management for OSINT; acquired by Maltego in 2025 (commercial)  
- [OctoParse](https://www.octoparse.com/) — No-code web scraping tool that turns pages into structured data (commercial)  
- [Web Scraper](https://webscraper.io/) — Point-and-click browser extension and cloud platform for web scraping (freemium)  
- [ShareX](https://getsharex.com/) — Screenshot capture, screen recording, and annotation tool for Windows (free)  
- [Bellingcat Auto Archiver](https://github.com/bellingcat/auto-archiver) — Python tool that archives social media posts, videos, and images from URLs listed in a Google Sheet (free)  
- [Browsertrix](https://webrecorder.net/browsertrix) — Browser-based web archiving platform from Webrecorder for crawling and curating web archives (free self-hosted, paid hosted)  
- [Ubikron](https://www.ubikron.com/) — OSINT research platform with graph analysis and enrichment; currently pre-launch, private beta has closed (waitlist)  

### Network and Relationship Mapping
- [BlackDot Videris](https://blackdotsolutions.com/videris) — Intelligence platform for OSINT investigations (commercial)  
- [Gephi](https://gephi.org/) — Open-source visualization for graphs and networks (free)  
- [Gephi Lite](https://lite.gephi.org/) — Browser-based version of Gephi for visual network analysis (free)  
- [Cytoscape](https://cytoscape.org/) — Open-source platform for visualizing complex networks and integrating attribute data (free)  
- [Neo4j](https://neo4j.com/) — Graph database commonly used to store and query investigative relationship data (freemium)  
- [yEd Graph Editor](https://www.yworks.com/products/yed) — Free desktop diagramming tool with automatic layout algorithms, handy for quick link-analysis diagrams (free)  
- [i2 Analyst's Notebook](https://i2group.com/solutions/i2-analysts-notebook) — Link and intelligence analysis software (commercial)  
- [Kumu](https://kumu.io/) — Relationship mapping and dynamic visualization platform (freemium)  
- [Maltego](https://www.maltego.com) — Graphical link analysis platform for OSINT and cyber investigations (commercial, free tier available)  
- [Palantir Gotham](https://www.palantir.com/platforms/gotham/) — Enterprise platform for investigations and intelligence (commercial)  
- [ShadowDragon](https://shadowdragon.io) — OSINT software platform for investigation through PAI data collection, link analysis, and monitoring (commercial)  

### Data Cleaning & Analysis
- [OpenRefine](https://openrefine.org/) — Open-source tool for cleaning, transforming, and reconciling messy data (free)  
- [Tabula](https://tabula.technology/) — Extracts tables from PDF files into CSV or Excel; stable but not updated since 2018 (free)  
- [Datasette](https://datasette.io/) — Explore and publish datasets as an interactive website and API (free)  
- [Jupyter](https://jupyter.org/) — Interactive notebooks for data analysis and documenting investigative workflows (free)  
- [Observable](https://observablehq.com/) — Collaborative notebooks combining code, data visualization, and prose (freemium)  
- [Timesketch](https://timesketch.org/) — Open-source tool for collaborative timeline analysis of events and forensic data (free)  

### Publishing & Data Storytelling
- [Datawrapper](https://www.datawrapper.de/) — No-code tool for building interactive charts, maps, and tables for reports (freemium)  
- [Flourish](https://flourish.studio/) — No-code platform for interactive charts, maps, and scrollable data stories (freemium)  
- [Infogram](https://infogram.com/) — Create interactive infographics, charts, maps, and dashboards (freemium)  
- [RAWGraphs](https://www.rawgraphs.io/) — Open-source tool for creating custom visualizations from tabular data, processed locally in the browser (free)  
- [TimelineJS](https://timeline.knightlab.com/) — Open-source tool from Knight Lab for building interactive timelines from a Google Sheet (free)  
- [draw.io](https://www.drawio.com/) — Free diagramming application that stores data locally (free)  
- [Excalidraw](https://excalidraw.com/) — Collaborative virtual whiteboard for sketching diagrams (free)  

### Standards & Safe Document Handling
- [Berkeley Protocol](https://www.ohchr.org/en/publications/policy-and-methodological-publications/berkeley-protocol-digital-open-source) — UN standards for gathering, analyzing, and preserving digital open source information in investigations of human rights and international crimes  
- [Dangerzone](https://dangerzone.rocks/) — Converts potentially dangerous PDFs, office documents, and images into safe PDFs by rendering them in a sandbox (free)
