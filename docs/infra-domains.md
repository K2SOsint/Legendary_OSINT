## 🌍 Domains, IPs & Infrastructure

[← Back to Index](../README.md)

### Registries and Whois
- [Whois](https://who.is) — Basic Whois lookup  
- [ICANN Lookup](https://lookup.icann.org/en) — Official ICANN Whois/RDAP lookup  
- [RDAP.org](https://about.rdap.org/) — Bootstrap server that redirects RDAP queries for domains, IPs, and ASNs to the authoritative registry  
- [ARIN](https://arin.net) — North America IP registry  
- [RIPE](https://ripe.net/) — Europe, Russia, Middle East IP registry  
- [APNIC](https://apnic.net) — Asia-Pacific IP registry  
- [LACNIC](https://lacnic.net) — Latin America and Caribbean IP registry  
- [AFRINIC](https://afrinic.net) — Africa IP registry  
- [Apnic WhoWas](https://www.apnic.net/static/whowas-ui/) — Historical APNIC Whois registration data for IP addresses and ASNs  
- [SIDN](https://sidn.nl) — Netherlands domain registry  
- [Eurid](https://eurid.eu/en/) — .EU domain registry  

### Domain Intelligence
- [DomainTools](https://domaintools.com) — Domain research platform  
- [DomainIQ](https://www.domainiq.com/) — Domain intelligence and history  
- [Completedns](https://completedns.com/dns-history/) — DNS history database  
- [IPQS](https://www.ipqualityscore.com/) — Toolbox for domain/IP intelligence, including proxy and VPN detection  
- [WhoisRequest](http://whoisrequest.com/history/) — Domain ownership history lookup  
- [Whoxy](https://www.whoxy.com/) — Parsed Whois API with reverse Whois search (paid, per-query pricing)  
- [SecurityTrails](https://securitytrails.com/) — DNS and infrastructure data (a Recorded Future company)  
- [Robtex](https://robtex.com/) — Infrastructure graph explorer  
- [Web-Check](https://web-check.xyz/) — All-in-one website analysis tool  
- [ICANN CZDS](https://czds.icann.org/) — Request access to zone files of participating gTLDs  
- [Tranco](https://tranco-list.eu/) — Research-oriented ranking of the most popular domains, hardened against manipulation  

### Certificates and DNS
- [crt.sh](https://crt.sh/) — Certificate Transparency logs  
- [Cert Spotter](https://sslmate.com/certspotter/) — Certificate Transparency monitoring from SSLMate (commercial, 30-day trial)  
- [DNSDumpster](https://dnsdumpster.com/) — DNS mapping and reconnaissance  
- [DNSlytics](https://dnslytics.com) — DNS, IP, and ASN intelligence  
- [ViewDNS](https://viewdns.info) — Multi-tool for DNS and Whois lookups  
- [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/) — Online DNS record lookup (A, AAAA, MX, TXT, CNAME, and more)  
- [HackerTarget](https://hackertarget.com/) — Online DNS, reverse IP, subdomain, and network scanning tools (free with usage limits)  
- [Internet.nl](https://internet.nl/) — Tests whether websites and email follow modern standards such as IPv6, DNSSEC, HTTPS, DMARC, and DANE  

### Technology Fingerprinting
- [BuiltWith](https://builtwith.com/) — Website technology profiler  
- [Wappalyzer](https://www.wappalyzer.com/) — Detect CMS, frameworks, and technologies (freemium)  
- [Netcraft Site Report](https://sitereport.netcraft.com/) — Site reports and hosting analysis  
- [Online Nikto scanner](https://nikto.online/) — Identifying Potential Vulnerabilities and Misconfigurations (Active & OSINT)  
- [SpyOnWeb](https://spyonweb.net/) — Shared analytics and advertising IDs  
- [JARM](https://github.com/salesforce/jarm) — Active TLS server fingerprinting tool that groups servers by TLS configuration, used to link related infrastructure  

### IP Tools
- [IPVoid](https://www.ipvoid.com/) — IP lookup and blacklist checks  
- [IP Location](https://iplocation.net/) — Approximate IP geolocation  
- [Maxmind](https://maxmind.com/) — Geo IP tool  
- [IPinfo](https://ipinfo.io/) — IP geolocation, ASN, and privacy detection data; free Lite tier with country-level data and ASN  
- [CentralOps](https://centralops.net/co/) — Network lookup toolkit (traceroute, nslookup, dig, whois, ping, Domain/Email Dossier)  
- [BroadbandSearch Network Tools](https://www.broadbandsearch.net/network-tools) — Free network diagnostic tools (successor to the old network-tools.com, which now redirects here)  
- [ping.pe](https://ping.pe/) — Ping, MTR, TCP, DNS, and BGP tests from 170+ locations worldwide  
- [Online Port scanner](https://portscanner.online) — Check Open Ports (Active Scanning & OSINT) for Target Host  
- [I Know What You Download](https://iknowwhatyoudownload.com/en/peer/) — Torrent history by IP  

### BGP, ASN & Routing
- [Hurricane Electric BGP Toolkit](https://bgp.he.net/) — Look up ASNs, IP prefixes, peers, and BGP routing information  
- [BGP.Tools](https://bgp.tools/) — Search and debug BGP data by ASN, IP prefix, DNS, or MAC address  
- [RIPEstat](https://stat.ripe.net/) — Internet data and analytics on IP addresses and ASNs, with a public API  
- [PeeringDB](https://www.peeringdb.com/) — User-maintained database of networks and interconnection points  
- [CAIDA AS Rank](https://asrank.caida.org/) — Ranking of autonomous systems and organizations by customer cone, from CAIDA topology data  
- [Team Cymru IP to ASN Mapping](https://team-cymru.com/community-services/ip-asn-mapping/) — Free bulk mapping of IP addresses to their ASN and BGP prefix  

### Internet Scanning & Exposure
- [Shodan InternetDB](https://internetdb.shodan.io/) — Free API showing open ports, vulnerabilities, and tags for an IP address, no API key required  
- [Shadowserver](https://www.shadowserver.org/) — Nonprofit with public dashboards and free reports on exposed and compromised systems  
- [Hunt.io](https://hunt.io/) — Threat hunting platform for discovering C2 servers and mapping malicious infrastructure  
- [FullHunt](https://fullhunt.io/) — Attack surface discovery and exposure monitoring via web and API  
- [Hunter](https://hunter.how/) — Internet search engine for security researchers  

### Internet Measurement, Outages & Censorship
- [Cloudflare Radar](https://radar.cloudflare.com/) — Global Internet traffic, security, DNS, and connectivity trends  
- [IODA](https://ioda.inetintel.cc.gatech.edu/) — Georgia Tech's real-time monitoring of Internet outages by country and network  
- [RIPE Atlas](https://atlas.ripe.net/) — Global network of probes for measuring Internet connectivity and performance  
- [NetBlocks](https://netblocks.org/) — Monitors connectivity disruptions and Internet censorship worldwide  
- [OONI Explorer](https://explorer.ooni.org/) — Open data on Internet censorship from over a billion network measurements  

### Domain Age and History
- [CarbonDate](https://carbondate.cs.odu.edu/) — Estimate when a domain was created  
- [Whois EasyCounter](https://whois.easycounter.com/) — Historical Whois and ownership details  
- [URL Dater](https://github.com/nixintel/urldater) — Validates the age of a domain and website content using RDAP, CT logs, and Last-Modified headers  

### Website Relationship & Similarity
- [SimilarSites](https://www.similarsites.com/) — Find websites similar to a given domain  
- [Similarweb](https://www.similarweb.com/) — Website traffic and competitive intelligence, with free traffic checking tools
