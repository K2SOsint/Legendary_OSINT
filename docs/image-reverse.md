## 📷 Image & Reverse Search

[← Back to Index](../README.md)

### Reverse Image Search Engines
- [Baidu Image](https://image.baidu.com/) — Reverse image search and AI image creation by Baidu  
- [Bing Visual Search](https://www.bing.com/visualsearch) — Reverse image search from Microsoft  
- [Google Images](https://images.google.com/) — Reverse image search and visual similarity  
- [Google Lens](https://search.google/ways-to-search/lens/) — Search by camera, image, or screenshot; identifies objects, text, and landmarks  
- [Yandex Images](https://yandex.com/images/) — Powerful reverse search, especially for faces and objects  
- [TinEye](https://tineye.com/) — Reverse image search with focus on older content  
- [SauceNAO](https://saucenao.com/) — Reverse image search across art, anime, and illustration databases  
- [Karma Decay](https://karmadecay.com/) — Reverse search for Reddit images (reported to be unreliable since Reddit's API restrictions)  

### Metadata Extraction
- [ExifTool](https://exiftool.org/) — Extract, read, and edit metadata in images, audio, and video (main site is currently a placeholder because its host disabled it; documentation and downloads are on the [SourceForge mirror](https://exiftool.sourceforge.net/))  
- [Metadata2Go](https://www.metadata2go.com/) — Online EXIF/metadata viewer for images, video, audio, and documents  
- [Pic2Map](https://www.pic2map.com/) — Extract GPS coordinates and EXIF data from a photo and show where it was taken  

### Image Forensics
- [Forensically](https://29a.ch/photo-forensics/) — Online forensic suite for images, processed locally in the browser  
- [FotoForensics](http://fotoforensics.com/) — Error Level Analysis and image authenticity tools  
- [Image Edited?](https://imageedited.com/) — Quick analysis of digital image edits  
- [MeVer Image Verification Assistant](https://mever.iti.gr/forensics/) — Web-based image forensics to help assess whether a photo has been manipulated  
- [Sherloq](https://github.com/GuidoBartoli/sherloq) — Open-source desktop toolset for digital image forensic analysis  
- [Aperi'Solve](https://www.aperisolve.com/) — Online layer and steganography analysis of images to reveal hidden data  
- [Content Credentials Verify](https://verify.contentauthenticity.org/) — Check an image's provenance and edit history when it carries C2PA Content Credentials  

### Image Enhancement & Object Identification
- [Photopea](https://www.photopea.com/) — Free browser-based photo editor for cropping, adjusting levels, and annotating images  
- [Upscayl](https://upscayl.org/) — Free, open-source AI image upscaler for Linux, macOS, and Windows  
- [iNaturalist](https://www.inaturalist.org/) — Community platform for identifying plants, animals, and fungi from photos; useful for placing a photo's location by its flora and fauna  
- [Pl@ntNet](https://plantnet.org/en/) — Plant identification from photos, backed by a citizen science database  

### Facial Recognition and Search
- [PimEyes](https://pimeyes.com/) — Face search engine (commercial)  
- [Betaface](https://betaface.com/demo_old.html) — Face recognition demo  
- [FindClone](https://findclone.ru/) — Russian facial recognition search engine
