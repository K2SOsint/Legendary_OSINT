## 👤 People Search & Social Media

### BlueSky

- [Clearsky](https://Clearsky.app) — Search for accounts and shows top listed/blocked accounts last 24h  
- [DeckBlue](https://Deck.blue) — Monitor Bluesky with a TweetDeck-style column dashboard  
- [BlueSky Feed Creator](https://blueskyfeedcreator.com/) — Build your own custom Bluesky feeds from hashtags, emojis, or keywords  
- [Internect](https://internect.info/) — Resolves a Bluesky handle or DID and shows the DID (ID), name history, server info and creation date  
- [PLC Directory](https://web.plc.directory/) — Public registry of `did:plc` identifiers used by Bluesky, with lookup and API for an account's DID document and handle history  
- [PDSls](https://pdsls.dev/) — Browse the raw AT Protocol data (records, repos, collections) of any Bluesky account (needs JavaScript)  
- [BlueSky Insights](https://bluesky-insights.dwagentai.com/) — Free, no-signup analytics on the growth of a Bluesky account  
- [BlueSky Directory](https://blueskydirectory.com/) — Large directory of curated Bluesky feeds, starter packs, and mute/block lists for certain topics or communities

### Facebook
- [StalkFace](https://stalkface.com/en/) — Browse a public Facebook profile's photos, posts, friends, likes, and places without logging in  
- [Lookup-ID](https://lookup-id.com/) — Find Facebook profile, group, and page IDs from URLs  
- [WhoPostedWhat](https://whopostedwhat.com) — Facebook keyword search for posts by date (the Instagram and Twitter tools on the same site are retired)  
- [SOWsearch](https://sowsearch.info/) — Free form that builds Facebook search links for posts, people, photos, pages, places, videos, and events, replacing the closed Graph Search (Facebook changes often break individual searches)

### VKontakte (VK)
- [VK Watch](https://vk.watch/ru) — Search for profiles, posts, videos, and groups (could not be verified automatically)

- [VK ID Lookup](https://regvk.com/id/) — Find a VK profile by numeric ID or slug  
- [vk_api (Python)](https://github.com/python273/vk_api) — Unofficial Python library for VK API access  
- [Wayback Machine](https://web.archive.org/web/*/vk.com/*) — View archived/removed VK content

- [VK History Robot](https://t.me/VKHistoryRobot) — Telegram bot to view VK profile history changes  
- [InfoVkUser Bot](https://t.me/InfoVkUser_bot) — Telegram bot to search for VK profiles by name (successor of FindNameVk_bot, which moved here)  
- [Дезертир](https://t.me/deserteer) — Telegram tool for VK-related OSINT (Russian)  
- [Barkov.net](https://vk.barkov.net/) — Toolkit of 300+ scripts to collect audience data from VK, Odnoklassniki, and Telegram, with a free plan

### X (former Twitter)

- [snscrape](https://github.com/JustAnotherArchivist/snscrape) — Scrape tweets, profiles, hashtags (last commit November 2023, its X/Twitter scrapers no longer work)  
- [Foller.me](https://foller.me/) — Analyze Twitter account topics & activity  
- [BirdHunt](https://birdhunt.huntintel.io/) — Historical tweet search  
- [Twitonomy](https://www.twitonomy.com/) — Analytics on tweets, mentions, followers, lists  
- [Botometer](https://botometer.osome.iu.edu/) — Bot-likelihood scoring for Bluesky and legacy Twitter accounts (Indiana University)  
- [Wayback Tweets](https://waybacktweets.streamlit.app/) — Retrieve deleted or archived tweets  
- [Nitter Instance Tracker](https://status.d420.de/) — Live uptime/status tracker for Nitter instances (alternative Twitter front-end); nitter.net itself is unreliable, use this to find a working instance

### Cross-Platform
- [Sherlock](https://github.com/sherlock-project/sherlock) — Username search across 400+ sites  
- [WhatsMyName](https://whatsmyname.app/) — Fast username enumeration across 600+ sites  
- [Epieos](https://epieos.com) — Powerful search tool from e-mail address / phone number to accounts  
- [Lolarchiver](https://lolarchiver.com) — Reverse lookup of e-mail address / phone number to accounts, X/Twitter account histories, and game-related usernames  
- [Maigret](https://github.com/soxoj/maigret) — Collect a dossier by username across 3,000+ sites  
- [Social Analyzer](https://github.com/qeeqbox/social-analyzer) — API, CLI, and web app for finding a person's profiles across about 1,000 social media sites  
- [Holehe](https://github.com/megadose/holehe) — Check if email is registered on platforms  
- [GHunt](https://github.com/mxrch/GHunt) — Offensive Google framework, used to investigate Google accounts from an email address  
- [Blackbird](https://github.com/p1ngul1n0/blackbird) — Find accounts by username and email across 600+ platforms  
- [Namechk](https://namechk.com/) — Username/domain availability  
- [Socialscan](https://github.com/iojw/socialscan) — Check username/email across services (last release January 2023)  
- [UserSearch](https://usersearch.com/) — Paid OSINT platform combining 18 search types and 100+ data sources with shared case management  
- [IDcrawl](https://www.idcrawl.com/) — Free people search aggregating social media profiles and public web information  
- [Pipl](https://pipl.com/) — Commercial identity intelligence platform for investigations and fraud prevention (enterprise-focused)
