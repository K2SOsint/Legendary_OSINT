### AI Search and Analysis
- [Perplexity](https://www.perplexity.ai/) — AI-powered search engine with cited sources  
- [Andi Search](https://andisearch.com/) — Conversational search engine with AI answers  
- [You.com](https://you.com/) — Web search API for grounding AI agents/LLMs in live results  

### AI for Media and Verification (Deepfake Detection)
- [Sensity AI](https://sensity.ai/) — Detect deepfakes and manipulated visual media  
- [Reality Defender](https://www.realitydefender.com/) — Real-time deepfake detection across audio, video, and images  
- [Hive AI-Generated Content Detection](https://hivemoderation.com/ai-generated-content-detection) — API to detect AI-generated and deepfake media  
- [AI or Not](https://www.aiornot.com/) — Detector for AI-generated text, images, audio, and video  

### AI Geolocation
- [GeoSpy](https://geospy.ai/) — Predicts a photo's location from visual features, no EXIF data required  
- [Picarta](https://picarta.ai/) — Predicts a photo's location from architecture, landscape, and signage  

### AI Transcription & Translation
- [Whisper](https://github.com/openai/whisper) — Open-source multilingual speech recognition, transcription, and translation model
